## 🧭 How I work · Cómo trabajo

- 🔍 **Understand the *why*, take care of the details.** I want to know the reasoning behind how things work, and I treat the details with care — that's where real value is created.<br/>
  <sub>**Entender el *porqué* y cuidar los detalles.** Busco conocer el razonamiento detrás de cómo funcionan las cosas y cuido cada detalle, porque ahí es donde se genera el valor real.</sub>
- 🔁 **Learn by building.** I turn new concepts into small, focused examples: it's the fastest way to understand how something truly behaves.<br/>
  <sub>**Aprender construyendo.** Convierto cada concepto nuevo en ejemplos pequeños y concretos: es la forma más rápida de entender cómo se comporta algo en realidad.</sub>
- 🔒 **Privacy by design.** Personal data is a responsibility, not an asset. I design so that each feature works with the minimum information necessary, keep that data as close to the user as possible, and make sure they always remain in control of it.<br/>
  <sub>**Privacidad por diseño.** Los datos personales son una responsabilidad, no un activo. Diseño para que cada funcionalidad opere con la mínima información necesaria, mantengo esos datos lo más cerca posible del usuario y me aseguro de que siempre conserve el control sobre ellos.</sub>
