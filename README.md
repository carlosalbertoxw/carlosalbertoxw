## 🧭 How I work · Cómo trabajo

- 🔍 **Understand the why, care about the details.** I like knowing why things work the way they do, and I pay attention to every detail, because that's where real value is added.<br/>
  <sub>**Entender el porqué y cuidar los detalles.** Me gusta saber por qué las cosas funcionan como funcionan y cuidar cada detalle, porque ahí es donde se agrega valor.</sub>
- 🔁 **Learn by building.** I usually build simple examples to understand how things really work.<br/>
  <sub>**Aprender construyendo.** Suelo construir ejemplos sencillos para entender cómo funcionan las cosas.</sub>
- 🔒 **Privacy first.** Handling personal data is a serious responsibility, so I avoid storing it whenever I can and prefer to leave users in control of their own information.<br/>
  <sub>**Privacidad primero.** Manejar datos personales es una gran responsabilidad, por eso evito almacenarlos siempre que puedo y prefiero que sean los usuarios quienes tengan el control de su información.</sub>
